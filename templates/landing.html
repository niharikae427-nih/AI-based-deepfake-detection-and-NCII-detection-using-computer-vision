About the Project

Built for academic research & real-world defense

SENTRA AI is a final-year computer vision project demonstrating how deep learning architectures — EfficientNet, XceptionNet, YOLO, and CNN-based spectral models — can be combined into a single platform to detect deepfakes and non-consensual intimate imagery. The current build ships with realistic placeholder inference so the full product experience, database, and reporting pipeline can be demonstrated end-to-end, with clearly marked integration points for production TensorFlow / OpenCV / Librosa models.
